# Code of Conduct

VantaLoader is intended to be a constructive project for people with different experience levels and backgrounds.

## Expected behavior

- Be respectful, patient, and specific.
- Critique ideas and implementations without attacking people.
- Assume good faith while remaining open to evidence and correction.
- Accept technical feedback professionally.
- Respect privacy and do not publish another person's private information.
- Keep discussion relevant and make room for newcomers.

## Unacceptable behavior

Harassment, discrimination, threats, intimidation, personal attacks, doxxing, deliberate disruption, and unwanted sexual attention are not acceptable in project spaces.

## Scope and enforcement

This policy applies to repository issues, discussions, pull requests, code review, and other spaces when someone is representing the project. Maintainers may edit or remove violating content and restrict participation when necessary.

To report a conduct concern, contact the repository owner privately through their GitHub profile. Do not use public issues for sensitive reports.
